# AI agenti v digitálním marketingu

Materiály k přednášce pro [Lipo.ink](https://lipo.ink), 20. 5. 2026, Liberec.

Přednášející: Marek Prokop, PROKOP software s.r.o.

## Prezentace

Slidy: **https://marekprokop.github.io/lipo-ink-ai-agents/**

Zdroj je v `slides.md` (formát [Marp](https://marp.app)).

## Co je v repozitáři

- `slides.md` — zdroj prezentace.
- `index.html` — vygenerovaná prezentace, servíruje ji GitHub Pages.
- `demo/` — složka, se kterou se pracuje v živých ukázkách: podklady, záznamy výletů a styl pro tvorbu obsahu.
- `demo-scenare.md` — scénáře obou živých ukázek.

## Spuštění prezentace lokálně

```
npm install
npm run preview   # živý náhled
npm run build     # vygeneruje index.html
```

## O čem přednáška je

Jak přejít od AI chatbotů (ChatGPT, Gemini) k AI agentům a používat je v marketingu a podnikání. Dvě živé ukázky s agentem Claude Code: příprava byznys plánu a tvorba obsahu na sociální sítě.
